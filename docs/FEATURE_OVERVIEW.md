# Feature overview

## Available / current

| Capability | Public positioning |
| --- | --- |
| Player and athlete profiles | Manage player and athlete context and history. |
| Live match logging | Record a karate match from a mobile-first experience. |
| Scores and penalties | Capture scoring and penalty activity during a match. |
| Review and history | Revisit structured match activity after completion. |
| Analytics | Review verified performance analytics where available. |
| Teams | Coach team management where enabled and verified. |
| Tournaments | Individual workflows and coach team workflows where verified. |
| Mobile delivery | Cross-platform Android and iOS application. |

## Roadmap / future

Public store release, PDF/report exports, AI-generated insights, video analysis, coach-athlete invitations, organization/academy accounts, federation/official organizer mode, a public marketplace, advanced sharing/permissions, and full commercial-plan enforcement are not currently available.
