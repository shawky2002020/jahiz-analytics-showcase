# Security policy

This repository intentionally contains no application source code, credentials, production configuration, private endpoints, or user data.

Please do not report suspected production vulnerabilities here. Use the approved public contact after it is added to the README. Until then, do not include vulnerability details in public issues.

If you find a secret, personal information, or an asset that should not be public in this showcase, open a documentation-feedback issue without reproducing the sensitive value. Maintainers should remove the material, rotate any exposed credential if applicable, and assess repository history before publishing.
