# Reviewed product captures

This directory contains eight privacy-reviewed Android captures from the installed Jahiz app. They cover the coach home, live logging, match review, match analytics, athlete profile management, coach team management, tournament workflow, and athlete self-profile experiences.

Each committed WebP has these safeguards:

- The underlying records are local fictional demo fixtures traceable to the product's demo seed utilities.
- The capture was inspected at full resolution for personal data, notifications, account identifiers, and private operational details.
- Original image metadata was absent; committed derivatives contain no EXIF, XMP, IPTC, or textual metadata.
- A non-product footer identifies every image as fictional demo data.

No browser capture, private source image, capture-session identifier, or unreviewed screen is included.
